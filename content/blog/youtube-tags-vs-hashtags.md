# YouTube Tags vs Hashtags

**YouTube tags vs hashtags** confuses people because both look like 'keywords.' They are different fields with different jobs. This page separates them so the [YouTube Shorts hashtags guide](/blog/youtube-shorts-hashtags-guide) can stay a hashtag list, and [YouTube tags](/blog/youtube-tags) can stay a tags-field explainer.

---

## Two fields, two jobs

| | Hashtags | Tags field |
| :--- | :--- | :--- |
| Where | Title or description, with `#` | Studio 'Tags' box, no `#` |
| Viewer sees it | Yes, as links | No |
| YouTube help stance | Connects videos that share a topic; up to 3 shown above the title | Useful for synonyms, misspellings, and extra context |
| Failure mode | Stuffing, unrelated tags, more than 60 | Keyword spam, repeating the title 12 times |

If you only do one, do hashtags plus a readable title. The tags field is a backup.

---

## What to type in each

**Title:** a sentence.  
`Why my Shorts stopped using 12 tags`

**Hashtags (description):** 3 to 5 labels.  
`#shorts #youtubetags #videoseo`

**Tags field:** synonyms and misspellings, comma separated.  
`youtube tags, youtube hashtags, shorts seo, you tube tags`

Do not put `#shorts` in the tags field. The `#` is not part of that field.

---

## Shorts vs long-form

Shorts discovery leans on the opening, the title, and whether people continue watching. Long-form still uses search more heavily, so the tags field can matter slightly more there as synonym coverage.

That does not mean Shorts should skip hashtags. It means you should not rebuild a 2008 tag-stuffing ritual for a 20-second video.

If the question is 'where do I put the `#`', that is [title vs description](/blog/youtube-shorts-hashtags-title-vs-description). If the question is 'which hashtags', that is the [hashtags guide](/blog/youtube-shorts-hashtags-guide).

---

## A default publish checklist

1. Title states the promise in normal words
2. Description has one sentence of context
3. 3 to 5 hashtags that match the video
4. Tags field: a handful of synonyms, not a paragraph
5. Spoken words match the title topic

## Common mix-ups

- **Pasting hashtags into tags.** Harmless but pointless. Use words, not `#`.
- **Pasting tags into the title.** Makes the title unreadable.
- **Using a tag generator for both.** Generators invent volume. If a suggested tag is not in the video, skip it. See [YouTube tag generator](/blog/youtube-tag-generator) only as a brainstorm, not as a source of truth.

YouTube tags vs hashtags is settled this way: hashtags are the public labels; tags are the quiet synonyms; the title is still the thing people click.
