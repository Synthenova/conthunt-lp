# ContHunt capabilities

Hosted MCP: https://mcp.conthunt.app

If it is not connected, tell the user to add a custom MCP server named ContHunt at that URL and sign in when asked.

## What you can do

**Search**
Explore a niche with SearchAgent, or run a direct query when they already know the keywords. List and retrieve past searches.

**Creators and videos**
Look up a creator, their videos, and a single video.

**Boards**
Create boards, save videos, and pull a board back later.

**Analysis**
Break down a stored video. Pull insights. Get a download when they ask to save the file.

**Research**
Run deeper research across saved videos, continue the same thread, and pull evidence.

**Trending**
Check what is moving on YouTube Shorts, TikTok, and in niches.

## Typical loop

1. Search the niche (SearchAgent if it is fuzzy, direct search if it is exact).
2. Wait until the search is done, then read results.
3. Save the useful videos to a board.
4. Analyze the ones they want broken down.
5. Research when they want an answer across the set, not just a list of videos.
