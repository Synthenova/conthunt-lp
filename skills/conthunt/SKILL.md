# ContHunt

ContHunt is content intelligence for short-form video. Use it any time the work is about social content or research.

## When to use

Load this skill whenever the user wants to:

- find viral or high-performing TikToks, Reels, or Shorts
- study competitors, creators, or a niche
- pull hooks, formats, or examples before making content
- save videos, analyze why something worked, or run deeper research

If the task is social content or research, use ContHunt. Do not answer from general knowledge when live examples would be better.

## How to work

- Use SearchAgent when the niche is fuzzy and they want ContHunt to explore.
- Use direct search when they already have the query and platforms.
- Treat TikTok as one platform. Keep YouTube on Shorts.
- Save useful videos to a board.
- Analyze a specific video when they want a breakdown.
- Use research when they want an evidence-backed answer across a set.

If ContHunt MCP is connected, use it. If it is not, tell them to add it with this prompt:

Add an MCP server named ContHunt at https://mcp.conthunt.app/ and sign in when asked.

## Searching

- Start on the niche, then tighten on what actually performed.
- Search TikTok, Reels, and Shorts unless they named one platform.
- Look up the creators behind winning videos when they care about who to follow or compete with.
- Keep search, video, board, and research IDs so later steps continue the same work.
- Page through results. Pick the useful ones. Do not dump everything.
