# Task 21 Authority Building Backlog

Date: 2026-04-16

Built from:

- `task-19-domain-authority-audit.md`
- `task-20-core-eeat-content-audit.md`

## Goal

Turn the domain audit into an execution backlog for authority, entity consistency, and editorial trust.

## Priority 1: Editorial Identity

### 1. Create stable author profile pages

- one page per named author already used in the blog build:
  - `Zach Sanders`
  - `Alex`
  - `Elena`
  - `Lamrin`
  - `Maya`
- include:
  - name
  - role
  - bio
  - topic coverage
  - profile image
  - links to recent articles

### 2. Add a public editorial standards page

- explain:
  - how articles are researched
  - when pages are updated
  - how corrections are handled
  - when ContHunt data is used versus external sources

### 3. Add an about/company page

- company name
- product description
- contact details
- ownership or operating entity
- why the site exists

## Priority 2: Entity Consistency

### 4. Normalize organization identity across the site

- keep one canonical company description
- use one consistent support email
- keep the same social profile URLs in schema and footer
- add the same company wording to legal pages, homepage schema, and future about page

### 5. Expand organization schema

- add stronger organization details where appropriate:
  - founding date
  - sameAs
  - support contact
  - company/about URL once published

### 6. Build third-party entity references

- create or improve:
  - LinkedIn company page
  - Crunchbase or equivalent startup/company profile
  - founder/company references on public profiles that can be cited

## Priority 3: Link and Mention Targets

### 7. Linkable assets to publish first

- `YouTube Shorts timing benchmark`
- `YouTube Shorts hook library`
- `Short-form creator workflow templates`
- `copyright-safe Shorts publishing checklist`

These are better link targets than generic trend posts.

### 8. Editorial link prospects

Focus on relevant outreach, not volume:

- creator economy newsletters
- social media marketing publications
- martech and SaaS blogs
- YouTube creator communities
- digital strategy agencies with resource pages

### 9. Mention-building targets

- guest contributions on creator marketing sites
- podcast appearances or quote contributions
- benchmark roundups where ContHunt data can be cited

## Priority 4: Trust Signals On Existing Pages

### 10. Add stronger source trails to high-impression posts

Start with:

- `youtube-shorts-best-practices`
- `best-time-to-post-youtube-shorts-2026`
- `can-you-use-copyrighted-music-on-youtube-shorts`

### 11. Add internal-link clusters around the winning topics

- hooks
- titles
- thumbnails
- timing
- analytics
- policy/safety

### 12. Add update discipline

- refresh top posts monthly if they are in the top-impression bucket
- record `updated` dates only when the content actually changed

## Suggested Sequence

### Week 1

- author consistency in build output
- author profile pages
- editorial standards page

### Week 2

- about/company page
- organization schema expansion
- refresh top 3 blog posts

### Weeks 3-6

- publish one linkable benchmark asset
- begin targeted outreach
- create third-party company/entity references

## Definition of Done

- named authors are consistent across UI, telemetry, and schema
- public editorial/process pages exist
- company identity is consistent across owned properties
- at least one citation-worthy research or benchmark asset is live
- outreach list exists with named targets and a live status tracker
